# AccessMind AI

## Start the app on Windows

From the project root, double-click `Open AccessMind.bat`. It starts the local
backend and frontend, waits for them to respond, and opens the app in your
browser. Keep the backend and frontend terminal windows open while using it.

The frontend is a Vite app, so opening `frontend/index.html` directly from the
file system does not start the app. For frontend-only development, run
`npm run dev` from the `frontend` directory.
